# Jogo da Velha Pixel

Jogo da velha para duas pessoas no mesmo dispositivo, com visual inspirado em
arcades e pixel art. Funciona em celulares e computadores, sem bibliotecas ou
etapas de instalação.

## Como jogar

1. Abra `index.html` no navegador.
2. X e O alternam as jogadas no mesmo tabuleiro.
3. Use **Reiniciar partida** para começar outra rodada.
4. Se X vencer, aparece um susto pixelado com efeito sonoro.
5. Se O vencer, aparece **"bem vindo ao VASCO DA GAMA"** com uma vinheta
	original de dois segundos, gerada no navegador.
6. Se a partida terminar empatada, um tomate pixelado cruza a tela com a
	mensagem **"perdeu, newba"**.

## Estrutura

- `index.html`: estrutura e conteúdo da página.
- `css/style.css`: identidade visual, animações e layout responsivo.
- `js/game.js`: regras, interação do tabuleiro e animação do empate.

## Tecnologias

HTML, CSS e JavaScript puro. Não há dependências externas.
